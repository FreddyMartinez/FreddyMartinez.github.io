# FreddyMartinez.github.io

Personal page / portfolio. React + Vite + React Three Fiber, deployed to GitHub Pages via Actions.

```sh
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```

Edit your info in `src/data.ts`.

**One-time setup:** in the repo on GitHub, go to *Settings → Pages → Build and deployment → Source* and pick **GitHub Actions**.
